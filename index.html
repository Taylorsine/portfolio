Projets en Réseaux, Systèmes & Sécurité

Chaque projet est conçu pour répondre à un besoin d'ingénierie réel, avec une architecture optimisée et une interface web interactive.

PROJET 1 • CYBER Port 3000

NetAudit

Scanner Réseau & Audit de Vulnérabilités

Moteur de reconnaissance périmétrique basé sur des sockets TCP non-bloquants. Analyse les ports ouverts, intercepte les bannières logicielles (*banner grabbing*), calcule un **Score de Sécurité (0-100)** avec notation par grade (**A-F**) et génère un plan de durcissement (*Hardening*).

Inclus : Scanner ARP pour trouver les IP d'amis sur le Wi-Fi en 1 clic.
Node.js Sockets SSE Temps Réel Analyse CVEs Export PDF / JSON
PROJET 2 • SRE Supervision SRE

SysPulse

Supervision Système & Gestionnaire de Tâches

Dashboard d'observabilité haute fréquence cadencé à 1 seconde via **Server-Sent Events (SSE)**. Affiche les courbes dynamiques de charge CPU/RAM (fenêtre glissante 30s), les débits réseau réels (RX/TX Ko/s), l'occupation disque, et un gestionnaire de processus avec arrêt forcé sécurisé (*Kill Task*).

Inclus : Alerting proactif automatique si CPU ou RAM > 85%.
Chart.js TSDB Flux SSE (1000ms) Task Manager Web SRE Golden Signals
PROJET 3 • RÉSEAU Architecture IP

IP-Master

Architecture d'Adressage IPAM & VLSM

Plateforme d'ingénierie d'adressage IPv4. Intègre un calculateur CIDR avec conversion binaire 32 bits pédagogique, un algorithme d'optimisation VLSM évitant tout gaspillage d'adresses, et un gestionnaire IPAM avec **Heatmap visuelle des 254 adresses** d'un sous-réseau.

Inclus : Heatmap 254 adresses avec assignation d'IP en 1 clic.
Bitwise Math 32b Algorithme VLSM Registre IPAM RFC 791 / 1918
